# BJUT 物理实验规范

在本仓库每次处理任务时使用本 skill，应用与本次任务有关的条款。用户最新明确要求优先；遵守其例外，不扩大修改范围。此 skill 固化规范，不自行授权发布、发送消息或修改其他项目。

## 报告内容：严格对应，不缺漏、不擅加

- 以用户给出的实验报告、手册页面、题目和最新标注为内容依据；现有代码辅助核对，不能替代未读过的报告原文。
- 修改前把本次涉及的报告要求与实现逐项对应：标题和编号、原始记录表、数据处理小问、计算量、公式、图表、结果表、思考题及分析讨论。保持原顺序、分组、符号、表头、单位、固定行和适用条件；不能因界面整理而丢项。
- 不自行增加题目、测量列、输入参数、统计指标、实验步骤、物理结论或大段背景。原报告要求计算的量须完整实现；为完成该项所需的公式、代入和单位换算属于必要计算内容，不算另加报告项目。
- 数据操作、校验提示等工作台帮助可单独呈现，不混入报告答案；开发术语、缓存机制、测试日志不写进实验报告正文。
- 原文缺失或某项要求不清时，完成不受影响的已授权工作，再精准确认缺失项；不能凭惯例补造内容，也不能宣称已完成报告全文对照。

## 数据忠实与更正范围

- 原始记录和参数以用户最新明确提供的版本为准；保留原始文本精度、顺序和空值。示例与用户录入持续区分，没有提供的测量值保持空白。
- 对异常、游标不一致或看似笔误的测量值，不自动改成更合理的值，不平滑、补齐或用理论值代替。保留记录，必要时在输入反馈或专项说明中指出，等待针对该值的明确更正。
- 执行交换、搬移和局部更正时，先明确行范围、列对应及例外。例：用户要求光栅一、二级左右交换、零级不迁移，必须交换八条谱线的对应Ⅰ／Ⅱ列，零级保持原位置。
- 固定编号、级次、已知波长等元数据保持身份与顺序；合法的 0 与缺测不同。角度 `30.10` 是 30°10′，以文本保留，不能当作十进制度数 30.1°。
- 参数、原始表和人工覆盖值属于同一份可恢复草稿。更新默认数据不覆盖已编辑的会话草稿；“载入示例”按现有确认流程替换。

## 计算：公式、代入、结果缺一不可

- 每个报告要求的计算项按“原始公式 → 当前数值代入与必要单位换算 → 合理取舍的结果及单位”呈现。只给公式或只给最终数值均不够；共用公式可写一次，各要求的组别和结果不能省略。
- 符号对应真实物理量，解释报告所需的量和单位。展示实际本轮输入，不硬编码旧样例；质量、几何量等改变后，所有依赖量随之更新。
- 表格、摘要、代入过程、图表和结果导出使用同一个输入版本及同一个 `ResultBundle`。计算保留精度，展示函数不重算另一套实验结果，也不把格式化字符串或舍入后的值送回计算。
- 根据实际有效记录数计算平均值和逐差值，只使用符合报告方法的有效测量对。缺测不当作零，缺失处不补造计算结果。
- 无法计算的量显示“—”和简短原因，正常缺测不当程序失败。非法值阻止当前计算并隐藏旧结果；物理方法、仪器常量或量纲疑点单独记录，不能用旧错误固化验收。

## 有效数字与数学呈现

- 先确认每个量的显示规则：报告明确要求、仪器分度／原始记录精度、该实验已确认的有效位数。区分小数位数与有效数字，不能把所有实验统一成同一位数或只按一个通用格式输出。
- 中间计算保留保护位；仅在最终呈现时取舍。数值代入需要足够保护位以复算；代入显示经过取舍时用 `≈`，不制造与结果表冲突的精确等式。
- 保留表达精度所需的末尾零，例如 `343.0`、`1.0%`、`7.70×10⁻¹⁹`。科学计数法的尾数遵守规定有效位数；整数计数、级次与精确常数按其语义处理。
- 百分数明确是否已经乘 100，长度、角度、电压、频率等先按公式换算单位。报告中使用正确的 `×10^n`、上下标、分式、角度和单位，避免原始 `e-19`、NaN／inf 或 LaTeX 源码泄漏。
- 误差和不确定度按该报告要求取位；若报告未规定，依据测量精度与已确认的实验规则说明取舍依据，不能武断设成两位。本项目已确认的密立根电荷／电子电荷为三位有效数字、相对误差为两位，平均时间按对应原始记录的最粗小数精度显示；其他实验不自动套用此规则。
- 修正精度时同时核对结果表、关键摘要、代入末端和导出。结果 CSV 保留用于复算的数值精度与单位，报告展示按上述规则格式化。

## 思考题和说明文字

- 保留原题与编号，在每题下直接给出简明回答；通常用一至三句讲清结论和必要原因，复杂题以完整回答为先。用户要求展开时再增加细节。
- 不新增思考题，不重复题干，不写泛泛背景或冗长总结。区分理论判断与本次数据能支持的实验结论，不编造观测现象。
- 中文实验内容使用清楚、平实的中文；原术语、符号和单位准确。分析讨论仅在报告要求或用户明确请求的范围内完成。

## 表格和图表

- 保持报告的表号、列顺序、单位和行身份，原始输入与计算结果分开。多组／多油滴／多级次都按要求完整呈现。
- 图表只实现报告或用户要求的图；坐标、单位、图例和实验标注齐全，多曲线同时用线型或标记区分。缺测处断线，不跨过缺点构造斜率或未测曲线。
- 像谐振截止频率这样的派生量由程序按已确认方法计算；有唯一合法交点时绘垂直虚线并标横轴数值，无唯一解时标为不可用。不要把可计算量改成人工输入来规避计算。
- 交互预览随主题适配；报告导出白底，保留曲线、单位与标注。检查中文、数学符号、刻度和图例可读，避免遮盖与裁切。
- 所有 Matplotlib 图（含原生图、Plotly 转报告图、预览及导出）统一调用 `core.fonts.report_style`；保存前通过公共 `figure_bytes` 应用字体，不能各实验自行选黑体、回退 DejaVu 或改成英文来掩盖缺字。中文优先宋体 `SimSun`／`Songti SC`，英文、数字和数学表达式优先 Times New Roman；字体列表拉丁在前、中文在后以实现逐字混排。缺少指定字体时，允许使用项目自带的思源宋体与 Liberation Serif，并在界面明确告知替代名称。不得将 Liberation Serif 宣称为实际 Times New Roman。
- 新增或修改 Matplotlib 图时，必须实际渲染并检查标题、坐标轴、图例、标注、中文、负号、希腊字母及上下标，缺字警告应使验收失败；同时测试只有项目开源字体可用的环境。PNG 栅格化、SVG 字形转路径、PDF 嵌入字体，避免接收端未安装字体后再次乱码。字体资源及许可证、来源和哈希一起维护，不将系统商业字体复制到公开仓库。
- 上下标、上标负号等指定字体缺失的 Unicode 科学符号以 Matplotlib 自带的 DejaVu Serif 逐字兜底；MathText 符号以 STIX 兜底，不更改普通英文／数字的首选字体。避免在同一个 Matplotlib MathText 字符串中混入中文；简单希腊符号可用 Unicode 与中文混排，复杂公式与中文说明分开绘制。验收同时检查 missing-glyph 警告和 MathText 的缺字日志，不能仅凭导出成功判定字体正常。

## 项目实现与验证

修改代码时按需读[数据契约和架构](../../../docs/architecture.md)，涉及公式疑点时读[专项数值说明](../../../docs/numerical-notes.md)。历史验收与哈希属于当时版本，不能当作修改后的当前验证。

- 延续 `app.py`、显式注册表、薄页面、公共工作台和数据类契约；新增实验不在通用页面中插入专用控制分支。`core` 和实验计算不依赖 `st.*`，不修改输入。
- Streamlit 工作同时遵守可用的 `developing-with-streamlit` skill。保持原生组件与主题；不引入全局 CSS、旧 AgGrid 路径或未要求的界面重做。
- 保留按实验隔离的草稿、稳定编辑源、替换操作后的编辑器版本及来源标识。输入区在结果标签外；输入变化立即使旧结果和下载失效，同版本不重复计算。
- 图表与导出按需准备；无图实验不提供图表视图，不能用异常表示“不支持”。不缓存可变用户对象，不累积旧版本图片；Matplotlib Figure 用完释放。
- 按改动选择验证：数据更正核对原记录及行列范围；计算或取位改动用独立复算和对应断言；内容改动逐项对照报告并检查公式渲染；交互改动做实际 Enter／Tab、粘贴、导入后编辑和章节往返，不能仅用 Session State 注入宣称真实录入通过。
- 大规模界面改动检查桌面与 390 px、浅／深色，整页不横向溢出，宽表局部滚动。性能结论使用同环境的可追溯旧／新版本证据，分开记录计算、首次绘图、重复查看和外部等待；小范围任务不强制重跑整套性能或浏览器验收。
- 仓库测试命令是 `.venv/bin/python -m unittest discover -s tests -v`；按改动运行相应范围并做 `git diff --check`。本地无写权限的字体缓存可用可写 `MPLCONFIGDIR` 和 `MPLBACKEND=Agg`；不把首次字体缓存构建计入计算优化结论。
- 收尾确认本次报告要求无缺漏、无擅加；公式与代入对应当前输入，精度和单位一致，更正范围包含明确例外。交付说明只报告实际改动和已验证结果，未执行的测试、浏览器操作、审校或发布明确区分。
