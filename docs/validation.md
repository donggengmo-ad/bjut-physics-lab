## 性能比较

使用同一台机器、同一个 Python 3.10／Streamlit 1.56 环境、相同现有字体缓存。旧版取实施前工作区快照，包含当时未提交的下册光栅和密立根模块，未用较早 Git HEAD 代替；[旧源码快照](qa/baseline-source.zip)与[环境及源码哈希](qa/environment-and-hashes.json)一并保留。

两个版本分别在独立进程内运行实际入口 AppTest。重复查看、连续参数编辑、章节往返各 7 个样本，表中为中位数，单位毫秒；这些是服务端脚本请求耗时，不是浏览器绘制、网络或人工录入延迟。光栅使用仅供测试的 d=2000 nm 理想角度，量化到分，不写入产品默认数据。

| 实验 | 重复查看：旧 → 新 | 连续参数编辑：旧 → 新 | 两页往返：旧 → 新 | 新版首次绘图 / 重复图表视图 |
|---|---:|---:|---:|---:|
| 弹性模量 | 107.6 → 24.2 | 123.9 → 27.0 | 187.2 → 47.6 | 64.7 / 25.5 |
| 谐振 | 73.6 → 24.0 | 75.9 → 29.6 | 620.2 → 47.4 | 60.3 / 28.4 |
| 光栅（测试角度） | 457.6 → 21.6 | 472.6 → 26.3 | 595.5 → 45.3 | 663.9 / 81.6 |

首次入口请求：旧版 2.251 秒，新版 1.349 秒；各为一个新进程样本，已有字体索引，不包含 pip 安装、HTTP 网络或首次字体索引构建。这不是统计显著性的启动速度结论。

旧版每次请求都计算、推导并绘图；没有独立的“首次打开图表”步骤，其成本包含在页面请求中。新版把该成本延迟到图表视图，所以上述改进主要来自版本复用与按需渲染，不能解释为物理计算算法本身快了同样倍数。章节往返包含下一代表实验，再返回当前实验，因此不同实验的旧版往返成本不同。

原始样本：[旧版](qa/performance-baseline.json)、[新版](qa/performance-candidate.json)。`selected_view_request_s` 是进入该测量段的请求；之前导航测量可能已访问此页，不把它称为全新页面冷启动。
