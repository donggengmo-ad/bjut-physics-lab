## 简介
bjut物理实验课的数据处理小工具，希望能帮到大家！

### 功能
- 在网页表格里输入数据，会自动计算实验报告要求填的数（比如平均值、误差等）
- 显示数据处理的公式推导、代入数据过程
- 下载表格，上传表格

### 补充
- 上册：弹性模量、扭摆、非均匀磁场、分光仪、牛顿环、弗兰克赫兹。
- 下册：实验二“交流电路的谐振现象”，包含表2-1至表2-4、两条谐振曲线、截止频率与带宽、理论谐振频率和品质因数计算。
- 排版比较粗糙，望见谅（）

## 使用方法

### 链接
[点击这里](https://bjut-physics-lab.streamlit.app)

### 说明
- 进入链接后，在左侧选择你要处理的实验
- 双击表格输入数据，按回车更新
- 下载或上传只支持csv格式，上传要保证表头和格式正确
- 详细信息参考网页顶部的 **数据说明** 和 **注意事项**
- 下册实验二的初始频率、电压已换算为书本使用的Hz、mV；实测谐振频率取测量电压最大值对应频率。程序按测量点连线与Imax/√2水平线的交点自动计算f1、f2（线性插值），画出垂直虚线并在横轴标出数值，同时计算Δf=|f2-f1|和Q4；没有唯一交点时暂不生成对应结果。
