# BJUT 物理实验工作台

bjut 物理实验课的数据处理小工具。输入测量记录后，自动整理结果、公式代入和实验图表。

所有 Matplotlib 预览及报告图片统一采用中文宋体、英文／数字 Times New Roman；环境缺少指定字体时，使用项目自带的思源宋体和 Liberation Serif，并在图表页提示实际字体。字体来源与许可证见 [assets/fonts](assets/fonts/README.md)，开发要求见 [架构说明](docs/architecture.md)。

## 支持的实验

- 上册：弹性模量、扭摆、非均匀磁场、分光计、牛顿环、弗兰克–赫兹。
- 下册：交流电路谐振、衍射光栅及其特性、声速测量、密立根油滴实验。

保留原有示例；衍射光栅默认使用用户提供的表 4-1 记录，照亮长度为 30 mm、光栅编号为 1，一、二级左右读数已按用户更正交换，零级保持原表位置。示例仅用于演示，请用自己的实验记录替换。

## 使用

[现有线上地址](https://bjut-physics-lab.streamlit.app)；本次改造尚未发布到线上。

1. 在侧栏选择实验。根地址默认打开弹性模量，各实验有稳定页面地址。
2. 双击原始表格编辑，按 Enter、Tab 或离开单元格提交；结果自动更新。固定行标识不可修改。
3. 在“结果表格”“计算过程”“图表”“实验说明”之间切换。有图表的实验才显示图表标签，打开后才绘图。
4. 使用“导入”恢复单张 CSV 或完整实验 JSON。先校验、再确认替换；失败不会覆盖草稿。
5. 使用“导出 → 准备备份与 CSV”生成当前输入的文件。完整实验 JSON 包含所有原始表、参数、人工覆盖值和来源，可在下次恢复。输入改变后需重新准备。

**草稿保留于当前浏览器会话。** 切换实验保留输入；刷新、关闭会话或服务重启后的恢复依靠完整实验文件。没有账号、数据库或浏览器持久化。

- 来源持续标注为“示例”“已修改示例”“CSV 导入”等；不同表来源不同时显示“混合来源”。
- 缺测不当作零；可用结果会显示有效记录数量。非法数值会定位到表、行、列，并隐藏对应旧结果与结果下载。
- “清空”只替换当前实验的测量值，保留固定行和参数默认值；清空、载入示例和文件替换均有确认。
- CSV 保留原列名和单位，并兼容旧文件中的 `Unnamed: 0` 索引列。度分角度建议填写文本 `30.10`（30°10′），不要把它理解成十进制度数。
- 浅色／深色从右上角菜单切换。手机上的宽表可在表格区域横向滚动。
- 图表中的“准备报告图片”提供当前版本的白底 PNG 和 SVG；交互图随界面主题适配。

下册谐振实验仍按测量电压最大值确定实测谐振频率；以测量点连线与 `Imax/√2` 的交点自动计算截止频率、带宽与 Q₄。没有唯一交点时不生成该项结果。密立根油滴可直接填写平均下降时间覆盖值，留空则恢复原始测量平均值。

## 本地启动与测试

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
python -m unittest discover -s tests -v
```

当前使用 Streamlit 1.56 的动态标签页接口。图像导出使用 Matplotlib Agg，不要求桌面图形窗口或额外的浏览器渲染服务。中文图表优先使用本机可用中文字体。
