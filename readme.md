# BJUT 物理实验工作台

BJUT 物理实验数据处理工具，支持测量记录录入、结果计算、公式代入和图表导出。

**[在线使用](https://bjut-physics-lab.streamlit.app)** · [使用反馈](https://wj.qq.com/s2/26323333/b51a/)

## 使用步骤

1. **选择实验**：在侧栏按册别选择实验。
2. **录入数据**：检查实验参数，双击单元格输入读数，按 Enter 或 Tab 提交。支持从表格软件批量复制粘贴。
3. **查看结果**：提交后自动计算，通过标签页查看结果、计算过程和图表。
4. **备份数据**：点击「导出 → 准备备份与 CSV → 下载完整实验」，保存 JSON 文件供后续恢复。

> 示例仅供参考，请使用实际测量记录。关闭或刷新页面前，请导出完整实验备份。

## 页面功能

| 页面 | 内容 |
| --- | --- |
| 结果表格 | 计算结果、单位及该实验的取位格式 |
| 计算过程 | 公式、当前数据代入和计算步骤 |
| 图表 | 实验曲线与报告图片导出；仅在支持绘图的实验中显示 |
| 实验说明 | 实验相关说明；部分实验附有思考题参考答案 |

## 保存、恢复和导出

| 文件 | 用途 | 操作入口 |
| --- | --- | --- |
| 完整实验 JSON | 备份与恢复原始表格、参数及数据来源 | 导出 → 准备备份与 CSV → 下载完整实验 |
| 输入 CSV | 保存单张原始数据表，也可用于导入替换该表 | 导出 → 准备备份与 CSV |
| 结果 CSV（ZIP） | 导出计算结果，供复算与整理 | 导出 → 准备备份与 CSV → 下载全部结果 CSV |
| PNG / SVG | 保存白底实验图，插入报告 | 图表 → 准备报告图片 |

**恢复记录**：点击「导入」，选择 JSON 或 CSV，再点击「检查并导入」。CSV 需选择对应输入表，并保留原列名和单位。

**更新导出**：修改数据后，需重新准备文件或图片。

## 图表与显示

- 报告图片使用白底，支持 PNG 和 SVG。
- 中文优先使用宋体，英文和数字优先使用 Times New Roman。
- 运行环境缺少指定字体时，使用自带的思源宋体和 Liberation Serif；图表页会显示实际使用的字体。
- 移动端宽表支持局部横向滚动；浅色、深色主题可从右上角菜单切换。

## 本地运行

安装 Python 后，在项目目录执行：

```bash
python -m venv .venv
```

激活环境：

| 系统 | 命令 |
| --- | --- |
| macOS / Linux | `source .venv/bin/activate` |
| Windows PowerShell | `.venv\Scripts\Activate.ps1` |

安装依赖并启动：

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

在浏览器打开终端显示的本地地址。
